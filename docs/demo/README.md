# A11yLens Product Demo

This interactive walkthrough presents the A11yLens workflow through actual application captures: scope selection, impact review, issue triage, element evidence, coverage, and exports.

The featured result comes from a fresh scan of the Tech Book Store public catalog in desktop and mobile viewports. The package includes the unchanged scan result, capture provenance, and self-contained HTML report.

Open `index.html` in a browser. The walkthrough supports arrow keys, Home and End, previous and next controls, and full-resolution screenshot links.
